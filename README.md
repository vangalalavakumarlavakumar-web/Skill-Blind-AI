# SkillBlind AI: Predictive Knowledge Gap Detection and Adaptive Learning Intelligence

Welcome to **SkillBlind AI**! The complete Next.js 15 production application is located in the [`skillblind-ai`](./skillblind-ai) directory.

### Quick Launch Instructions

```bash
cd skillblind-ai
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

For complete documentation, system architecture, database schema, and judge evaluation instructions, see [**`skillblind-ai/README.md`**](./skillblind-ai/README.md).
